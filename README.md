## Description
Application Java utilisant JPA et Hibernate avec une base H2 en mémoire.
Elle permet d'insérer et de lire des produits (entité `Produit`).

## Technologies
- Java
- Hibernate 5.6.5 / JPA
- H2 Database
- Maven
- IntelliJ IDEA
